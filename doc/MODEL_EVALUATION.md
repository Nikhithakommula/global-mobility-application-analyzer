# GMAA - Model Evaluation

## Selected Model
LightGBM Classifier

## Evaluation Metrics

| Metric | Score |
|---|---:|
| Accuracy | 75.36% |
| Precision | 78.02% |
| Recall | 87.89% |
| F1-Score | 82.66% |
| ROC-AUC | 78.94% |

## Metric Interpretation

- **Accuracy:** Correct predictions out of all predictions.
- **Precision:** How many predicted positive cases were actually positive.
- **Recall:** How many actual positive cases the model identified.
- **F1-Score:** Balance between precision and recall.
- **ROC-AUC:** Ability to distinguish between the two classes.

## Model Selection

LightGBM was selected for its classification performance and ability to handle structured tabular data.

## Note
These results are based on the project's test dataset. Predictions are intended for academic decision-support purposes and should not replace expert review.
